# Hospital Management System

This is a full stack hospital management system website written in Flask (Python), SQLAlchemy and Vue.js

## Three panels 
- Patient Panel
- Doctor Panel
- Admin panel


Admin can CRUD doctors and Patients.

Doctors can create scheduled date, give prescription and feedback to patient.

Patient can book slots and get prescriptions etc
